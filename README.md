# S1 Lumen

Stage1st 论坛（stage1st.com/2b）的 Chrome 扩展：重新设计的亮暗主题，加上续读、引用跳转和长帖工具。第三方扩展，与论坛官方无关。

需要 Chrome 109 或更新版本。

## 安装

1. 打开 `chrome://extensions`。
2. 打开右上角的「开发者模式」。
3. 点「加载已解压的扩展程序」，选择 `s1-lumen` 文件夹。

## 设置

点工具栏上的扩展图标：

| 设置 | 可选项 | 默认 |
|---|---|---|
| 主题 | 跟随系统 / 浅色 / 深色 | 跟随系统 |
| 日间配色 | Lumen / S1 原版 | Lumen |
| 夜间文字亮度 | 原始 / 自动 / 手动（76–98%） | 原始 |
| 帖子字号 | 14–22px | 16px |
| 讨论页宽度 | 标准 / 宽屏 | 宽屏 |
| 头像形状 | 圆形 / 圆角方形 | 圆形 |
| 页面切换淡入 | 开 / 关 | 关 |
| 帖子过渡动画 | 开 / 关 | 开 |
| 相对时间 | 开 / 关 | 开 |
| 显示签名档 | 开 / 关 | 关 |
| 默认显示敏感图片 | 开 / 关 | 关 |
| 登录时获取隐藏内容凭证 | 开 / 关 | 开 |
| 记住阅读位置 | 开 / 关 | 开 |

快捷键：`⌘K` 或 `/` 聚焦搜索框，`⌘B`（Windows 上 `Ctrl+B`）隐藏或展开侧栏。

## 功能

- **续读**：帖子列表里，读过的帖子标题后显示 `+12` 这样的新回复数，点它回到上次读到的楼层。重新进入帖子时，底部会出现「接着读 57 楼」。
- **引用跳转**：点引用会滚动到原楼层，底部出现「返回 57 楼」，一键回到刚才的位置。
- **翻页**：帖子顶栏除了上一页、下一页，还有直达首页和末页的按钮。
- **楼层拖动条**：多页帖子的右边缘有一条细线，拖动可以直接到达任意楼层，跨页也一样。
- **图片与附件**：顶栏的「图片 12 张 · 附件 2 个」把本页的图片和附件集中到一个窗口查看。
- **敏感图片**：标题含 NSFW 的帖子，图片默认遮挡，可以在顶栏按帖子显示。
- **隐藏内容**：显示“作者被禁止或删除 内容自动屏蔽”的楼层多一个「查看内容」按钮。已经被删除的内容读不到。
- **夜间文字亮度**：调暗夜间的白字，减轻散光看到的光晕。「自动」把正文压到 APCA 对比度约 Lc 68，也可以手动调，调过之后能一键重置回自动的亮度。灰色文字几乎不变，用户自定义的彩色文字保持原样，日间模式不受影响。
- **屏蔽**：悬停楼层信息点「屏蔽」，或在扩展弹窗里填关键词。被屏蔽的回复折叠成一行，相关主题在板块列表里隐藏。

## 隐私

扩展没有自己的服务器，只向论坛发请求，没有统计或上报，也不加载论坛页脚的 cnzz 统计。

查看隐藏内容需要论坛 App 接口的凭证。登录框里有一个默认勾选的「同时获取隐藏内容凭证」，勾选时扩展会用这组账号密码向论坛换取凭证。密码只发给论坛，不保存；取消勾选就不会读取。完整说明见 [PRIVACY.md](PRIVACY.md)。

## 开发

样式改 `src/`，然后运行 `pnpm build`。
