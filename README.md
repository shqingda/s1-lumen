# S1 Lumen

Stage1st 论坛（stage1st.com/2b）的 Chrome 扩展：重新设计的亮暗主题，并解决刷新和切换板块时的页面闪烁。

基于 Manifest V3，最低支持 Chrome 109（Windows 7/8 的最后一个版本）。低于 126 时帖子过渡退回普通淡入，低于 124 时切换页面可能短暂看到未加载完的内容。

## 安装

1. 打开 `chrome://extensions`。
2. 打开右上角的「开发者模式」。
3. 点「加载已解压的扩展程序」，选择 `s1-lumen` 文件夹。

## 设置

点工具栏上的扩展图标：

| 设置 | 可选项 | 默认 |
|---|---|---|
| 主题 | 跟随系统 / 浅色 / 深色（也可在左下角账号菜单里切换） | 跟随系统 |
| 日间配色 | Lumen / S1 原版（只影响浅色，选深色时隐藏） | Lumen |
| 帖子字号 | 14–22px | 16px |
| 讨论页宽度 | 标准（960px）/ 宽屏（1320px） | 宽屏 |
| 头像形状 | 圆形 / 圆角方形 | 圆形 |
| 页面切换淡入 | 开 / 关 | 关 |
| 帖子过渡动画（进出帖子和帖子内翻页时，标题随之移动） | 开 / 关 | 开 |
| 相对时间 | 开 / 关 | 开 |
| 显示签名档 | 开 / 关 | 关 |
| 默认显示敏感图片（标题含 NSFW 的帖子） | 开 / 关 | 关 |
| 登录时获取隐藏内容凭证 | 开 / 关 | 开 |
| 记住阅读位置 | 开 / 关（关闭时清空已有记录） | 开 |

板块页固定为 1120px 的标准版式，不提供设置。`⌘K` 或 `/` 聚焦搜索框，`⌘B`（Windows 上 `Ctrl+B`）或侧栏顶部的按钮可以完全隐藏、再展开侧栏，状态会记住。版规和板块随机图默认收起，点标题栏的「版规」展开。

窗口变窄时版式会自动调整：960px 以下侧栏变成顶栏，760px 以下设置页的分区变成横向标签，640px 以下板块列表单独占一行，帖子列表只保留标题和回复数。

配色和组件细节参考 shadcn/ui 的 neutral 主题，只用黑白灰：主按钮是反相的黑底白字（暗色主题为白底黑字），暗色背景为 `#0a0a0a`。所有颜色都在 `css/tokens.css` 里。

## 续读与引用跳转

- 帖子列表里，读过的帖子标题后会显示 `+12` 这样的数字，表示上次位置后面还有多少楼，点它直接回到上次读到的楼层。
- 每个帖子只记一个位置：离开帖子时所在的楼层，新位置直接覆盖旧位置。“只看该作者”和倒序浏览不记录。
- 从外面重新进入读过的帖子时，不论进的是哪一页，底部都会出现「接着读 57 楼」。点了之后不动，位置保持 57 楼；继续滑动或翻页就更新；不点就以离开时的楼层为准。
- 刷新、浏览器后退和恢复标签页都直接回到原来的楼层，不弹提示。位置在滚动停下时也会保存，强退浏览器不会丢。
- 点引用区域的任意位置，会平滑滚动到原楼层并短暂高亮，底部出现「返回 57 楼」，一键回到刚才的位置。不在当前页的楼层会在本标签页跳转，「返回」同样可用。按住 ⌘ / Ctrl 点击仍是新标签页打开。

## 长帖工具

- **楼层拖动条**：多页帖子的右边缘有一条细线，代表整个帖子。悬停显示页码和楼层，拖动松手直接到达，跨页也一样。窄屏不显示。
- **图片与附件**：顶栏的「图片 12 张 · 附件 2 个」把本页所有图片和附件集中到一个窗口，可以左右翻看、下载原图，也能跳回所在楼层。只统计当前页，因为读取其他页会增加查看数。
- **敏感图片**：标题含 NSFW（不分大小写）的帖子，图片默认用毛玻璃遮住，GIF 和 WebP 等格式同样有效。顶栏的「显示敏感图片」只改当前帖子，在关闭标签页之前有效，优先于设置里的默认值。
- **隐藏内容**：显示“作者被禁止或删除 内容自动屏蔽”的楼层多一个「查看内容」按钮，内容来自论坛的 App 接口。这个接口不认网页登录，所以登录成功时扩展会用同一组账号密码换一个凭证；已经登录的话，第一次查看时输一次密码。被真正删除的内容读不到。
- **屏蔽**：悬停楼层信息点「屏蔽」，或在扩展弹窗里填关键词。被屏蔽的回复折叠成一行，可以展开或解除；被屏蔽用户发的主题和标题含关键词的主题，在板块列表里直接隐藏。

## 为什么不再闪

Stylus 是在页面开始绘制之后才异步注入样式的，所以每次跳转都会先露出一帧原版的浅色页面。这个扩展改了三处：

- 样式写在 `manifest.json` 的 `content_scripts.css` 里，在页面构建之前就已挂上，不存在先后竞争。
- 主题设置同步保存一份在 `localStorage`，`document_start` 时读取，第一帧就是对的主题。
- 用 `<link rel="expect" blocking="render">` 让浏览器等到主要内容解析完再绘制，最多等 600ms，超时自动放行。

这个等待期间浏览器还显示着上一页，点击会被丢弃，所以页面刚切换的约 200ms 内点击可能无效。等待时间已尽量压短，鼠标悬停在板块链接上时也会预取页面，让这段时间更短。「页面切换淡入」只是新页面内容的一段透明度动画，不使用视图过渡，不会挡住点击。

## 开发

样式源码在 `src/`，可以使用嵌套和 `light-dark()`。`css/` 和 `popup/popup.css` 是构建产物，已提交到仓库，所以不构建也能直接加载扩展。改完样式后运行：

```bash
pnpm install
pnpm build
```

打包上架用的 zip，输出到 `dist/`：

```bash
pnpm package
```

构建会把样式合并压缩成一个文件，并把选择器末尾的 `:is()` 展开。Chrome 按选择器末尾的类名、ID 或标签给规则建索引，`:is()` 结尾的规则没有索引，要在每个元素上都试一遍。上架资料在 `store/`。

## 隐私与性能

- 只申请 `storage` 权限，没有 `host_permissions`，不加载任何远程代码，没有统计或上报。
- 设置保存在 `chrome.storage.sync`，并在论坛域名的 `localStorage` 里存一份，用于第一帧读取主题。
- 屏蔽名单随设置保存在 `chrome.storage.sync`，不发给论坛，只在本机生效。
- 登录框里会显示「同时获取隐藏内容凭证」，只有这个勾选开着时才读取表单里的账号密码。完整说明见 [PRIVACY.md](PRIVACY.md)。
- 隐藏内容凭证（`sid`）保存在 `chrome.storage.local`，不同步，页面脚本读不到，只发给论坛的 App 接口。密码不保存：登录时在内存里留到论坛答复为止，网页登录失败就丢弃，最多一分钟。退出论坛或关闭「登录时获取隐藏内容凭证」都会删除凭证。只在 HTTPS 下工作，请求不带 Cookie。
- App 接口返回的帖子是别人写的，插入页面前按白名单过滤：去掉脚本、表单、框架和事件属性，链接和图片只留 http(s)。
- 阅读位置只保存在本机论坛域名的 `localStorage` 里（最多 400 个帖子），不同步也不上传。
- 页脚的 cnzz 统计是同步脚本，服务器慢时会让页面迟迟完成不了解析，所以不加载它。不影响论坛功能，只是论坛的 cnzz 统计里不再计入你的访问。
- 只向论坛自身发请求：登录提交后请求一次 `forum.php` 确认状态；鼠标悬停在板块或翻页链接上时，浏览器预取该板块页。帖子页不预取，避免增加查看数。
- 全局样式不用 `*` 这类通配选择器，吸顶栏不用 `backdrop-filter`，省去每个元素的匹配和滚动时的合成开销。
- 不在 `<body>` 上使用 `:has()` 这类重算开销高的选择器，动态内容的处理按帧合并。
- 系统开启「减少动态效果」时，过渡和动画会缩到最短。

## 文件

| 路径 | 内容 |
|---|---|
| `content.js` | 主题、渲染闸门、侧栏构建、相对时间、帖内颜色适配、版规和随机图折叠、投票和登录后刷新、板块页预取 |
| `src/css/` | 样式源码，构建后合并成 `css/lumen.css`。`remap.css` 由站点 CSS 生成，不要手改 |
| `popup/` | 工具栏设置面板 |
